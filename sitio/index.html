Plantillas

Elige una plantilla o crea la tuya con tu propio contenido.

Para crear una: escribe el mensaje en Contenido (usa {{Ticket}}, {{ID}}… para lo que cambia) y pulsa Guardar actual como plantilla. Usar una plantilla reemplaza el contenido actual (puedes deshacerlo).
